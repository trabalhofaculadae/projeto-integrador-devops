Como esta página chega até você

Cada alteração no código passa por um pipeline automático antes de chegar à produção:

  1. Git pushO código vai para o GitHub.
  2. BuildO site é gerado a partir do código-fonte.
  3. TestesTestes automáticos validam o conteúdo.
  4. Imagem DockerA aplicação é empacotada e publicada no GHCR.
  5. DeployO servidor baixa a imagem nova e troca o contêiner.
